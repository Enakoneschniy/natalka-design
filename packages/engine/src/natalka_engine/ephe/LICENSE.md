# Swiss Ephemeris data files

`sepl_18.se1`, `semo_18.se1`, `seas_18.se1` — planetary, lunar and main-asteroid ephemeris files
covering 1800-01-01 … 2399-12-31, © Astrodienst AG. Distributed under the Swiss Ephemeris licence
(AGPL-3.0 **or** the commercial "Swiss Ephemeris Professional" licence). They are used only through
`pyswisseph`, which is the single AGPL dependency this project allows. Before the public launch the
Professional licence must be purchased — see `packages/engine/README.md`.

Source: https://github.com/aloistr/swisseph/tree/master/ephe
